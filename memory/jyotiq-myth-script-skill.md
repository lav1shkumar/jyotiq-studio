Since 2026-11-09, mythological storytelling reels for Jyotiq go through the `jyotiq-myth-script` skill (~/.claude/skills/jyotiq-myth-script). It returns three hooks, a recommended hook, one voiceover of 80 s or less, the word count and duration, and a source note.

**Why:** Ayush wants to approve the story before any assets are made; "approved" covers only the script, not production.

**How to apply:** Make no images, video, voiceover or Remotion code until he explicitly asks for production. Then follow the skill's references/visual-direction.md (reference sheets, then three visual tests, then storyboard and prompts), and hand the build to [[jyotiq-video-work]]. Visual reference is @theepictalesindia (inspiration only, never its watermark).
